Concepts de base
Définition
Qu'est-ce qu'un SIG ?
Système d'Information Géographique — outil de collecte, stockage et analyse de données spatiales.

Un SIG est un système informatique permettant de collecter, stocker, manipuler, analyser et restituer des données référencées géographiquement. Contrairement à un simple plan ou une carte papier, le SIG lie chaque objet spatial à une base de données attributaire interrogeable.

Cas d'usage agents : cartographier les travaux de voirie en cours et consulter l'état d'avancement par clic sur l'objet ; gérer les réseaux d'eau avec les caractéristiques de chaque canalisation ; suivre les dossiers de permis de construire par parcelle.
Vecteur
Mode vecteur : points, lignes, polygones
Des objets géométriques discrets, chacun associé à une fiche d'attributs.

Point : coordonnées X,Y. Ex : mairie, borne incendie, captage d'eau. Chaque point possède des attributs (nom, code INSEE, date de contrôle...).

Ligne (polyligne) : succession de sommets. Ex : route, cours d'eau, canalisation. Attributs : longueur, nature revêtement, débit...

Polygone : surface fermée. Ex : parcelle cadastrale, zone inondable, bâtiment. Attributs : surface, propriétaire, destination...

Point clé : on peut interroger, filtrer et modifier chaque objet individuellement. C'est la force du vecteur pour la gestion métier.
Raster
Mode raster : grille de pixels
Une image géoréférencée dont chaque cellule porte une valeur numérique.

Un raster est une grille régulière de cellules (pixels), chacune stockant une valeur. La résolution spatiale détermine le niveau de détail.

Orthophoto : photographie aérienne redressée géométriquement. Résolution typique IGN : 20 cm.

MNT : chaque pixel = altitude en mètres. Utilisé pour calculer pentes, bassins versants, zones inondables.

Limite : on ne peut pas cliquer sur "un objet" dans un raster — on lit la valeur d'une cellule. Pour des analyses objet par objet, le vecteur est préférable.
Interface utilisateur
Panneau
Panneau Couches
Liste et ordre d'affichage de toutes les couches du projet.

Le panneau Couches liste toutes les couches chargées. L'ordre dans le panneau détermine l'ordre d'affichage : la couche du haut s'affiche au-dessus des autres.

Cocher/décocher pour afficher/masquer ; glisser-déposer pour changer l'ordre ; clic droit pour accéder aux propriétés, zoom sur la couche, export.

Règle d'or : les polygones doivent être placés SOUS les lignes et les points, sinon ils les masquent.
Panneau
Panneau Explorateur
Navigateur de fichiers et connexions aux sources de données.
Outils
Barres d'outils
Navigation, sélection, édition — les raccourcis visuels essentiels.

Navigation : zoom avant/arrière (molette souris), déplacement (pan), zoom sur l'emprise totale. Raccourci : Z zoom, X dézoom.

Sélection : par clic (objet unique), par rectangle, par polygone libre. La sélection se matérialise en jaune sur la carte.

Édition : active via le crayon (mode édition). Permet d'ajouter, déplacer, modifier ou supprimer des objets.

Raccourcis clés : Ctrl+Z annuler, Ctrl+S sauvegarder, F5 rafraîchir, F6 table d'attributs.
Statut
Barre de statut et projets (.qgz)
Coordonnées, échelle, SCR actif et gestion des fichiers projet.

Barre de statut (en bas) : affiche en temps réel les coordonnées du curseur, l'échelle courante (modifiable), le SCR du projet (clic pour changer).

Fichier projet (.qgz) : enregistre la liste des couches et leurs chemins relatifs, la symbologie, les mises en page. Il ne contient PAS les données sources.

Bonne pratique : toujours organiser projet et données dans un même dossier racine pour que les chemins relatifs restent valides si le dossier est déplacé.
Fenêtre
Fenêtre principale — vue carte
La zone centrale affiche les couches — navigation, sélection et édition s'y effectuent.

La fenêtre principale (canevas cartographique) est l'espace de visualisation central. Le clic droit sur la carte ouvre un menu contextuel selon l'outil actif.

Vues multiples : QGIS permet d'ouvrir plusieurs vues de la même carte (Vue > Nouvelle vue cartographique) à des échelles différentes.

Astuce : maintenir la molette enfoncée (ou la touche espace) pour passer temporairement en mode déplacement, quelle que soit l'outil actif.
Installation
Version
LTR vs version courante
La LTR garantit stabilité et support long terme pour les environnements professionnels.

Version LTR (Long Term Release) : maintenue et corrigée pendant 1 an minimum. Recommandée pour les postes en production, les formations et les environnements où la stabilité prime.

Version courante : nouvelles fonctionnalités toutes les 4 mois mais plus susceptible de contenir des régressions. Pour les utilisateurs avancés.

Recommandation formation : utiliser la même version LTR sur tous les postes pour garantir une expérience identique entre participants et formateur.

Gestion des données et projections
Import de couches, formats géographiques et systèmes de coordonnées
4 h
Ajout de couches
Format
Shapefile (.shp)
Format historique, très répandu dans les services publics.

Le Shapefile est un ensemble de plusieurs fichiers obligatoires : .shp (géométrie), .dbf (attributs), .shx (index), .prj (projection). Sans le .prj, QGIS ne connaît pas le SCR.

Import : glisser-déposer le fichier .shp dans QGIS, ou Couche > Ajouter une couche vecteur.

Limites : nom de champ limité à 10 caractères, taille max 2 Go, un seul type de géométrie par fichier.

Conseil : lors du partage, toujours compresser le dossier entier en .zip — si un fichier manque, la couche ne s'ouvre pas.
Format
GeoPackage (.gpkg)
Format moderne recommandé : un fichier unique qui contient tout.

Base de données SQLite géospatiale. Un seul fichier .gpkg peut contenir plusieurs couches vecteur et raster, de la symbologie et des métadonnées.

Avantages : un seul fichier à partager, pas de limite de nom de champ, pas de limite de 2 Go, compatible avec tous les SIG modernes.

Créer un GeoPackage : clic droit sur une couche > Exporter > Enregistrer les entités sous... > choisir le format GeoPackage.
Systèmes de coordonnées
France
Lambert 93 — EPSG:2154
Projection officielle pour la France métropolitaine depuis 2009.

Le Lambert 93 est la projection de référence légale pour les données géographiques en France métropolitaine. Unité : mètres.

Coordonnées typiques : X ≈ 800 000 m, Y ≈ 6 500 000 m pour un point en France centrale.

Utilisation : toutes les données IGN (BD TOPO, BD ORTHO, cadastre), données de l'État et des collectivités.

Vérification : si vos coordonnées X sont entre 100 000 et 1 300 000 et Y entre 6 000 000 et 7 200 000, vous êtes en Lambert 93.
WGS84
WGS84 (EPSG:4326) et Web Mercator (EPSG:3857)
Les deux projections mondiales les plus courantes — GPS et cartographie web.

WGS84 (EPSG:4326) : système de référence mondial utilisé par les GPS. Coordonnées en degrés décimaux (latitude/longitude). Ex : Longitude = -1.09, Latitude = 49.11 pour Saint-Lô.

Web Mercator (EPSG:3857) : projection utilisée par Google Maps, OpenStreetMap, Bing Maps pour les tuiles raster web. Coordonnées en mètres mais déformations importantes aux hautes latitudes.

Attention : ne pas calculer de surfaces ou distances en EPSG:4326 (degrés) ou EPSG:3857 — les résultats seraient erronés. Toujours reprojeter en Lambert 93 pour les calculs métriques.

Manipulation et analyse de données
Table d'attributs, calculs, jointures et géotraitements
5 h
Table d'attributs
Base
Ouvrir la table (F6) — objet ↔ ligne
Chaque ligne de la table correspond à un objet géographique sur la carte.

Raccourci F6 ou clic droit sur la couche > Ouvrir la table d'attributs. Chaque ligne = un objet géographique, chaque colonne = un attribut.

Cliquer sur une ligne dans la table sélectionne l'objet correspondant sur la carte (surbrillance jaune). Le bouton en bas à gauche bascule entre "toutes les entités" et "entités sélectionnées uniquement".

Astuce : Ctrl + clic pour sélectionner plusieurs lignes ; Shift + clic pour une plage continue.
Filtrage
Sélection par formulaire et par expression
Sélectionner les entités répondant à des critères attributaires.

Sélection par formulaire : clic sur l'icône formulaire. Interface intuitive avec menus déroulants. Exemple : sélectionner toutes les parcelles d'un propriétaire donné.

Sélection par expression : puissante, permet des requêtes complexes :

"SURFACE" > 5000 — parcelles de plus de 5 000 m²

"COMMUNE" = 'Saint-Lô' AND "ETAT" = 'En cours'

Après sélection : exporter uniquement les entités sélectionnées en nouvelle couche, ou leur appliquer une symbologie différente.
Tri
Tri et recherche dans la table
Trier par colonne, rechercher une valeur, afficher seulement la sélection.

Tri : cliquer sur l'en-tête d'une colonne pour trier par ordre croissant ou décroissant. Un deuxième clic inverse l'ordre.

Recherche rapide : la barre en bas de la table permet de filtrer les lignes affichées sans sélectionner. Pratique pour trouver rapidement une entité dans une grande table.

Entités sélectionnées : cliquer sur "Afficher les entités sélectionnées" pour ne voir que les lignes sélectionnées — facilite le contrôle après un filtre.

Édition
Modifier, ajouter, supprimer des attributs
Activer le mode édition (crayon) pour modifier les valeurs des cellules.

Cliquer sur le bouton crayon (Ctrl+E) pour activer le mode édition. Les cellules deviennent modifiables directement dans la table.

Ajouter un champ : bouton "Nouveau champ" — définir le nom, le type (texte, entier, décimal, date) et la longueur.

Supprimer un champ : bouton "Supprimer un champ" (attention, irréversible après sauvegarde).

Toujours sauvegarder (Ctrl+S) puis quitter le mode édition pour valider les modifications.
Calculateur de champs
Calcul
Créer un champ calculé
Générer automatiquement des valeurs depuis la géométrie ou d'autres champs.

Mode édition activé > icône calculatrice dans la barre de la table, ou Ctrl+I.

Créer un nouveau champ : cocher "Créer un nouveau champ", nommer le champ, choisir le type et saisir l'expression.

Mettre à jour un champ existant : décocher "Créer un nouveau champ" et sélectionner le champ cible dans la liste.

Expression surface : $area / 10000 pour obtenir la surface en hectares (en Lambert 93, $area retourne des m²).
Expressions
Expressions courantes
Géométrie, texte, conditions — les fonctions les plus utiles en pratique.

Géométrie : $area surface en m², $length longueur en m, $perimeter périmètre, $x et $y coordonnées du centroïde.

Texte : upper("nom") majuscules, concat("prenom", ' ', "nom") concaténation, left("code", 2) premiers caractères.

Conditionnel : if("surface" > 10000, 'Grande', 'Petite')

Date : now() date et heure actuelles, year(now()) année courante.

Conseil : utiliser "Prévisualisation du résultat" en bas de la fenêtre pour vérifier l'expression avant de l'appliquer à toute la couche.
Sélection
Mettre à jour un champ sur une sélection
Appliquer le calcul uniquement aux entités sélectionnées — pas à toute la couche.

Dans le calculateur de champs, cocher "Mettre à jour uniquement les entités sélectionnées" pour limiter l'opération à la sélection active.

Utile pour : corriger les valeurs d'un sous-ensemble, initialiser un champ de statut pour un groupe, mettre à jour la date de contrôle pour les sites visités.

Exemple : sélectionner les parcelles traitées ce mois-ci, puis mettre à jour leur champ "DATE_CONTROLE" avec to_date(now()).
Jointures attributaires
Principe
Relier un tableau à une couche géo
Lier un Excel/CSV à une couche via un identifiant commun (code INSEE, ID parcelle...).

La jointure enrichit une couche géographique avec des données d'un tableau externe en les reliant via un champ commun aux deux sources.

Condition : les deux tables doivent avoir un champ avec des valeurs identiques (même format, même écriture). Ex : code INSEE "50447" dans la couche communes ET dans le CSV statistiques.

Configuration : clic droit sur la couche > Propriétés > onglet Jointures > bouton "+" > définir la couche à joindre, le champ source et le champ cible.

Exemple concret : joindre un CSV de population par commune (avec code INSEE) à la couche des limites communales pour cartographier la densité de population.
Vérification
Valider et gérer les NULL
Identifier les entités non appariées et comprendre les valeurs NULL.

Après la jointure, ouvrir la table d'attributs. Les nouveaux champs joints apparaissent à droite. Une valeur NULL signifie qu'aucune correspondance n'a été trouvée.

Causes fréquentes : espaces ou caractères différents ('50447' vs '50 447'), types incompatibles (texte vs entier), codes absents d'un côté.

Rendre la jointure permanente : exporter la couche pour figer les champs joints. La jointure dynamique est perdue si le projet est fermé sans export.

Géotraitements
Outil
Zone tampon (buffer)
Créer une zone à X mètres autour d'objets (routes, points, polygones).

Accès : Vecteur > Outils de géotraitement > Zones tampons, ou rechercher "Buffer" dans la boîte à outils de traitement.

Paramètres clés : couche source, distance en mètres, nombre de segments (arrondi des coins), option "Dissoudre le résultat" pour fusionner les zones qui se chevauchent.

La distance peut être fixe ou variable (lire la distance dans un champ attributaire).

Cas d'usage : zone de 35 m autour d'un cours d'eau (servitude), zone de 500 m autour d'un captage (périmètre de protection), zone de 50 m autour d'une voie ferrée.
Outil
Découpage (clip)
Extraire la partie d'une couche dans une zone d'étude.

Découpage (clip) : extrait les géométries d'une couche A qui se trouvent à l'intérieur d'une couche B (masque). Seule la géométrie est découpée, les attributs sont conservés.

Utilisation typique : extraire les routes d'une commune depuis un réseau régional, extraire les parcelles d'un secteur depuis la couche nationale.

Attention : la couche de découpe (B) doit avoir le même SCR que la couche à découper (A). Reprojeter si nécessaire avant le découpage.
Outil
Intersection, union et différence
Opérations booléennes entre deux couches pour créer des nouvelles géométries.

Intersection : similaire au découpage mais les attributs des DEUX couches sont fusionnés dans le résultat. Utile pour savoir quels objets de A se trouvent dans quelles zones de B.

Union : combine les deux couches en préservant toutes les géométries des deux.

Différence : soustrait la couche B de la couche A — retourne les parties de A non recouvertes par B.

Exemple : intersection entre zones tampons de cours d'eau et couche parcellaire → identifie les parcelles en zone de servitude, avec les attributs des deux couches.
Boîte
Boîte à outils de traitement
Accéder à tous les algorithmes QGIS/GDAL/GRASS depuis un seul panneau.

Accès : Traitement > Boîte à outils ou Ctrl+Alt+T. Donne accès à des centaines d'algorithmes organisés par fournisseur (QGIS natif, GDAL, GRASS, SAGA).

Recherche par mot-clé : taper le nom de l'outil dans la barre de recherche. Plus rapide que de naviguer dans les menus.

Historique : les derniers outils utilisés apparaissent dans l'onglet "Récents" pour les relancer rapidement.

Modèle graphique : pour des chaînes de géotraitements répétitives, utiliser le Modeleur graphique (Traitement > Modeleur graphique) pour automatiser la séquence.

Représentation cartographique, étiquetage et plugins essentiels
4 h
Représentation cartographique
Symbologie
Carte catégorisée
Une couleur différente par valeur de catégorie — type d'OCS, statut...

Choisir "Catégorisé" dans le menu déroulant, puis sélectionner le champ de classification et cliquer sur "Classer".

QGIS attribue automatiquement une couleur différente à chaque valeur unique du champ choisi.

Personnalisation : double-cliquer sur un symbole pour le modifier, modifier les libellés de la légende, supprimer des catégories de l'affichage.

Conseils couleur : utiliser des rampes ColorBrewer "qualitatives" pour les catégories — conçues pour être lisibles et différenciables, y compris pour les daltoniens.
Symbologie
Carte graduée
Un dégradé de couleurs selon une valeur numérique — population, surface, indice...

Choisir "Gradué", sélectionner le champ numérique et définir le nombre de classes.

Méthodes de discrétisation :
— Intervalles égaux : classes de même amplitude.
— Quantiles : même nombre d'objets par classe (pour distributions asymétriques).
— Jenks (ruptures naturelles) : minimise la variance interne — souvent la meilleure pour la carto thématique.
— Écart-type : classes définies autour de la moyenne.

Règle : 5 classes est le maximum recommandé pour une carte lisible. Au-delà, l'œil ne distingue plus les nuances.
Affichage et couleurs
Affichage
Visibilité par échelle
Afficher ou masquer des couches automatiquement selon le niveau de zoom.

Dans les propriétés de la couche > onglet Rendu : cocher "Visibilité dépendant de l'échelle" et définir les échelles minimale et maximale.

Exemples :
— Étiquettes des communes : visibles uniquement à partir du 1:50 000
— Numéros de parcelles : uniquement à partir du 1:5 000
— Couche de fond détaillée : masquée au-delà du 1:500 000

Améliore les performances et évite la surcharge visuelle aux petites échelles.

Couleurs
ColorBrewer et rampes cartographiques
Des palettes de couleurs conçues spécifiquement pour la cartographie thématique.

ColorBrewer 2.0 (colorbrewer2.org) propose trois types de rampes :
— Séquentielle : dégradé d'une teinte pour valeurs ordonnées (clair = faible, foncé = fort)
— Divergente : deux couleurs contrastées autour d'un point central (négatif ↔ positif)
— Qualitative : couleurs très différentes pour des catégories sans ordre

Ces rampes sont directement intégrées dans la liste des palettes QGIS.

Option "Daltonisme" : ColorBrewer indique si une rampe est adaptée aux personnes daltoniennes — important pour les cartes à diffusion publique.
Placement
Placement automatique et ajustements manuels
QGIS place les étiquettes automatiquement — intervenir sur les chevauchements persistants.

Onglet Placement : définir la priorité de placement (au-dessus, en dessous...) et les règles de collision.

Déplacement manuel : activer la barre d'outils d'étiquettes > outil "Déplacer une étiquette". Chaque déplacement est stocké comme "épingle" dans la couche.

Conseil : ne pas chercher à corriger tous les chevauchements en mode édition — à la mise en page, ajuster seulement les étiquettes visibles à l'échelle finale.
Expressions
Étiquettes basées sur des expressions
Concaténer plusieurs champs ou calculer la valeur à afficher dynamiquement.

Au lieu d'un champ simple, utiliser une expression dans le champ "Valeur" de l'étiquette :

concat("NOM", '\n(', round("SURFACE_HA", 1), ' ha)')
→ affiche le nom ET la surface sur deux lignes

if("STATUT" = 'En cours', upper("NOM"), "NOM")
→ affiche le nom en majuscules si le chantier est actif

Le \n dans les expressions d'étiquette crée un saut de ligne — pratique pour les étiquettes multi-lignes.

Mise en page et création d'atlas
Composeur d'impression, règles TOLE, atlas automatisé et export

Composeur d'impression
Mise en page
Créer une nouvelle mise en page
Espace de composition dédié, indépendant de la vue carte principale.

Projet > Nouvelle mise en page d'impression (ou Ctrl+P). Donner un nom — plusieurs mises en page peuvent coexister dans un même projet.

Format de la planche : clic droit sur la planche > Propriétés de la page — définir le format (A4, A3, A0...), l'orientation et la résolution.

Règle et grille : afficher la règle et activer la grille magnétique pour aligner les éléments précisément.

Résolution : 150 DPI pour affichage écran, 300 DPI pour une impression papier de qualité professionnelle.
Règles
Règles cartographiques TOLE
Titre, Orientation, Légende, Échelle, Source — les 5 éléments obligatoires.

T — Titre : élément "Label". Descriptif et précis. Ex : "Réseau d'eau potable — commune de Saint-Lô — 2024". Grande police, en haut de la planche.

O — Orientation : élément "Image" > flèche Nord dans la bibliothèque QGIS ou SVG personnalisé. Positionner en coin.

L — Légende : élément "Légende". Dans les propriétés, filtrer pour n'afficher que les couches visibles. Modifier les libellés, supprimer les éléments inutiles.

É — Échelle : élément "Barre d'échelle" graphique. La barre graphique reste correcte même si la carte est photocopiée à une taille différente.

S — Source : élément "Label" avec source des données. Ex : "Sources : IGN BD TOPO 2023 — EPSG:2154 | Réalisation : Service SIG".

Design
Positionnement, alignement et design
Outils d'alignement pour un résultat professionnel et cohérent.

Sélectionner plusieurs éléments : Shift + clic. Le menu Éléments > Aligner les éléments permet d'aligner gauche, droite, centrer.

Verrouiller les éléments : clic droit > Verrouiller pour éviter les déplacements accidentels une fois positionnés.

Cadre et marges : définir des marges régulières (ex : 5 mm sur tous les côtés) pour un aspect professionnel.

Modèle : une fois une mise en page satisfaisante créée, la sauvegarder comme modèle via Mise en page > Enregistrer comme modèle pour la réutiliser.
Cadre
Cadre, marges et cartouche professionnel
Les finitions visuelles qui distinguent une carte professionnelle d'une carte brouillon.

Cartouche d'informations : regrouper titre, légende, sources et échelle dans une zone dédiée (souvent en bas ou à droite), séparée de la carte par un filet fin.

Cadre de carte : dans les propriétés de l'élément Carte, activer le cadre (border) pour délimiter visuellement la zone cartographiée.

Logo ou identité visuelle : ajouter le logo de la collectivité via l'élément "Image" pour les productions officielles.

Cohérence : utiliser une seule police sur toute la mise en page, deux tailles maximum (titre + corps), et une gamme de couleurs en accord avec la charte graphique du service.
Création d'atlas — point fort de la formation
Atlas
Principe et configuration de l'atlas
Générer automatiquement N fiches cartographiques depuis une couche de couverture.

L'Atlas génère automatiquement une page de mise en page par entité de la couche de couverture.

Activer l'Atlas : dans le composeur d'impression > panneau Atlas (à droite) > cocher "Générer un atlas" > choisir la couche de couverture.

Paramètres de zoom : "Marge autour de l'entité" définit l'espace autour de chaque entité. "Échelle fixe" impose une même échelle pour toutes les fiches — utile pour une présentation homogène.

Couche de couverture : une couche de polygones simples (communes, EPCI, secteurs de travaux, îlots cadastraux). Chaque polygone = une fiche.
Variables
Titres dynamiques avec variables d'atlas
Le titre et les textes changent automatiquement à chaque fiche grâce aux variables.

Dans un élément Label, utiliser des expressions avec variables d'atlas entre crochets [% ... %] :

[% @atlas_pagename %] — nom de l'entité courante

[% "NOM_COMMUNE" %] — valeur d'un champ de la couche de couverture

[% concat("Fiche N°", @atlas_featurenumber, " / ", @atlas_totalfeatures) %] — numérotation automatique

[% format_date(now(), 'dd/MM/yyyy') %] — date de génération

Légende dynamique : activer "Uniquement les entités dans la carte" dans les propriétés de la légende pour qu'elle ne montre que les éléments visibles sur la fiche courante.
Configurer la couche d'atlas
Choisir la couche qui pilote la série — une entité = une fiche.
Dans le panneau Atlas : sélectionner la couche de couverture (ex : communes, parcelles, secteurs de travaux)

Nom de page : choisir le champ dont la valeur sera utilisée comme nom de chaque fiche (ex : "NOM_COMMUNE"). Ce champ alimente la variable @atlas_pagename.

Filtrage : une expression de filtrage permet de limiter l'atlas à un sous-ensemble d'entités (ex : seulement les communes d'un département, seulement les parcelles à statut "À traiter").

Tri : définir un champ de tri pour ordonner les fiches (alphabétique par nom, numérique par code...).

Prévisualisation et export en lot
Naviguer entre les fiches et exporter toute la série en PDF ou images.
Dans la barre d'outils Atlas, cliquer "Prévisualiser l'atlas" puis naviguer avec les flèches pour vérifier chaque fiche avant export

Export PDF multi-pages : Atlas > Exporter l'atlas en PDF > choisir le dossier et le nom. Toutes les fiches dans un seul PDF.

Export images individuelles : Atlas > Exporter l'atlas en images > chaque fiche génère un PNG ou JPEG nommé automatiquement.

Nommage automatique : l'expression de nom de fichier [% "NOM_COMMUNE" %]_fiche crée des fichiers nommés par commune — pratique pour les retrouver.
Export et intégration
Export PDF pour rapports administratifs
Haute résolution, vectoriel, idéal pour les documents officiels.
Export PDF : Mise en page > Exporter au format PDF

Options : résolution DPI (300 pour impression), export du texte comme chemin (pour fidélité à l'impression) ou comme texte (pour la recherche dans le PDF).

Pour les rapports : le PDF est le format de référence pour les transmissions officielles et les archives. Taille de fichier maîtrisée avec les paramètres de compression.

Astuce compression : cocher "Compresser le PDF" pour réduire la taille du fichier sans perte de qualité visible à l'impression.
Export image (PNG/JPEG) pour insertion
Pour insérer la carte dans Word, PowerPoint ou un e-mail.
Export image : Mise en page > Exporter comme image

PNG : format sans perte, recommandé pour les cartes avec textes et couleurs franches. Taille de fichier plus importante que JPEG.

JPEG : format compressé, léger pour les e-mails et documents Word. Légère perte de qualité acceptable pour les Orthophotos ou fonds dégradés.

Résolution : 150 DPI pour une insertion écran dans Word ou PowerPoint. 300 DPI si le document sera imprimé ensuite.

Export SVG et partage du projet
SVG pour l'édition graphique avancée, .qgz + données pour le partage complet.
Export SVG :

Format vectoriel, éditable dans Inkscape ou Illustrator pour des retouches graphiques finales (habillage personnalisé, infographies). Attention : les rasters ne sont pas vectoriels dans le SVG exporté.

Partage du projet : le fichier .qgz seul ne suffit pas — il faut fournir toutes les données liées. Options :
— Compresser projet + dossier de données dans une archive ZIP
— Utiliser un GeoPackage unique contenant toutes les couches
— Projet > Archiver le projet (QGIS 3.20+) pour regrouper automatiquement

Sauvegarde du projet et bonnes pratiques
Organiser ses fichiers pour éviter les liens cassés et faciliter le partage.

Prise en main et exploration d'un jeu de données communal
Guidé
Module 1 — Durée : 1h30
Ouvrir un projet QGIS fourni contenant les limites communales d'un département, un réseau routier et une couche de points (mairies). Explorer l'interface et identifier chaque panneau.
  1. Ouvrir le projet .qgz fourni par le formateur
  2. Identifier les types de couches (vecteur/raster) dans le panneau Couches
  3. Utiliser le zoom et la navigation pour explorer le territoire
  4. Ouvrir la table d'attributs de la couche communes et identifier les champs
  5. Changer l'ordre des couches pour modifier l'affichage
Import d'un fichier CSV de points de suivi de travaux
Pratique
Module 2 — Durée : 1h
Importer un fichier texte contenant des coordonnées GPS de chantiers, vérifier l'encodage et le SCR, puis reprojeter en EPSG:3949.
  1. Ouvrir le CSV dans un éditeur texte pour identifier le séparateur et l'encodage
  2. Importer via Couche > Ajouter une couche de texte délimité
  3. Vérifier que les points s'affichent au bon endroit sur la carte
  4. Exporter la couche en GeoPackage dans le SCR EPSG:3949
Jointure et calcul : superficie des parcelles par propriétaire
Pratique
Module 3 — Durée : 2h
Joindre un tableau Excel de propriétaires à une couche parcellaire, calculer la superficie en hectares et sélectionner les parcelles supérieures à 5 ha.
  1. Installer l'extension Spreadsheet layers dans QGIS
  2. Configurer la jointure dans Parcelles > Jointures
  3. Vérifier les champs joints dans la table d'attributs
  4. Ouvrir le calculateur de champs, créer le champ "superficie_ha" avec $area / 10000
  5. Filtrer par expression pour sélectionner les parcelles > 5 ha
  6. Exporter la sélection en nouvelle couche
Carte thématique de l'occupation du sol

Codes EPSG à retenir
  • EPSG:2154 — Lambert 93, projection officielle France métropolitaine
  • EPSG:4326 — WGS84 géographique (coordonnées GPS en degrés)
  • EPSG:3949 — UTM Zone 31N, projection utilisée pour la Manche
  • EPSG:3857 — Web Mercator (Google Maps, OSM, tuiles web)
  • EPSG:4171 — RGF93 géographique (variante française de WGS84)
Règles cartographiques TOLE
  • Titre — descriptif, précis, daté si nécessaire
  • Orientation — flèche Nord ou indication de l'axe
  • Légende — tous les symboles expliqués, unités précisées
  • Échelle — barre graphique et/ou rapport numérique
  • Source — auteur, organisme, date des données, projection
